OLLAMA + NOMIC-EMBED-TEXT SETUP (http://localhost:11434):
- download ollama image
- verify gpu presence using command:
   docker info | grep -i runtime

   nvidia should be listed
- execute command:
    docker run -d --name ollama -p 11434:11434 -v ollama_data:/root/.ollama ollama/ollama

  Pass "--gpus all" at starting if GPU present.
- execute command to pull qwen2.5-coder LLM model inside ollama:
    docker exec -it ollama ollama run qwen2.5-coder:3b

    POST http://localhost:11434/v1/chat/completions
        "model": "qwen2.5-coder:3b",
        "messages": [
            {"role": "system", "content": "You are a precise technical writer. Summarize the following code file in 3 concise bullet points."},
            {"role": "user", "content": f"Code:\n\n{file_content}"}
        ]
- execute command to pull nomic-embed-text embedding model inside ollama:
    docker exec -it ollama ollama pull nomic-embed-text

    curl http://localhost:11434/api/embeddings -d '{
        "model": "nomic-embed-text",
        "prompt": "Hello world"
      }'

  The model will be stored in mounted volume ollama_data
- Hit the `curl http://localhost:11434/api/tags` command which should print model details.


CHROMA DB SETUP (http://localhost:8000):
- download & run chromadb image with command:
    docker run --volume=chroma-data:/chroma -p 8000:8000 -d chromadb/chroma:1.5.9

- alternative to using LLM model inside ollama. We can seperately install vLLM with Qwen/Qwen2.5-Coder-3B-Instruct model:
    docker run --gpus all -p 8000:8000 --ipc=host --name vllm-coder -v ~/.cache/huggingface:/root/.cache/huggingface vllm/vllm-openai:latest --mod
    el Qwen/Qwen2.5-Coder-3B-Instruct --max-model-len 4096 --gpu-memory-utilization 0.75

    POST http://localhost:8100/v1/chat/completions
    "model": "Qwen/Qwen2.5-Coder-3B-Instruct",
    "messages": [
        {"role": "system", "content": "You are a precise technical writer. Summarize the following code file in 3 concise bullet points."},
        {"role": "user", "content": f"Code:\n\n{file_content}"}
    ]
- GET http://localhost:8000/api/v2 - heartbeat
  GET http://localhost:8000/api/v2/collections - get collections
  POST http://localhost:8000/api/v2/collections - post collections
  POST http://localhost:8000/api/v2/collections/{collection_name}/add - add collections
  POST http://localhost:8000/api/v2/collections/{collection_name}/query - execute a query
